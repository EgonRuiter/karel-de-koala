# Karel de Koala — Uitgebreide Python Editie (Archief / Optioneel)

Deze map bevat de volledige Python/Tkinter-versie van Karel de Koala (met de **7-tab Sticky BK Super-Hub**, **10 Arcade mini-games**, **16 tosti-recepten**, **StickyDex** en **`launch_karel.command`** voor macOS/Linux).

De **standaard Zero-Install editie** voor de RP2350 USB-stick staat in [`../desktop/`](../desktop/) (`karel_native.exe`).

## Starten vanaf deze map
- **Windows:** dubbelklik `launch_python.bat` (of run `desktop\launch_karel.bat --python`). Vereist Python 3 + Tkinter.
- **macOS / Linux:** run `bash python_extended/launch_karel.command` (vereist Python 3 + Tk `>= 8.6`).
